# Integration Notes

This branch intentionally integrates two closely related control-plane capabilities that were developed sequentially before the repository adopted a formal PR workflow:

1. local social-video learning and ingestion;
2. design-system/UI-library policy for generated applications.

The branch name reflects only the second capability and is therefore broader in content than its name suggests. This mismatch is recorded rather than rewriting published branch history.

The integration PR should be squash-merged so `main` receives one coherent reviewed commit. Future changes should keep one logical concern per short-lived branch as documented in `docs/GIT_WORKFLOW.md`.
